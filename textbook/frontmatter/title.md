# PhysiBot

**AI Physical Models for Mobile Robotics**

A full-course textbook and example project centered on the AgileX Limo Pro
(simulation first; physical robot and Orin Nano deploy later), with lab
backend compute on NVIDIA DGX Sparks.

Working brand: **PhysiBot**.

License: [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/) (narrative).
Code samples: [Apache-2.0](../../LICENSE-CODE).

Audience: mixed undergraduate / graduate. Linear algebra is refreshed in
Chapter 02; probability and estimation are taught as needed.
